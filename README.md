## 專案摘要

一套整合股票資料查詢、技術指標、策略訊號、視覺化與簡易回測的桌面分析工具。系統將原本分散的 SQL 查詢、指標判讀與歷史驗證流程整合在同一個 GUI，讓使用者能以固定條件或自然語言取得資料，再比較多種策略訊號。

## 專案資訊

- **開發期間：** 2026-07-23 ～ 2026-09-22
- **專案性質：** 資料庫系統實作專題課程
- **專案主題：** 金融資料分析與 AI 應用技術
- **應用範圍：** 股票資料查詢、技術分析、策略訊號、圖表呈現與簡易回測

## 解決的問題

股票分析資料分散在資料庫查詢、指標計算與圖表判讀等不同步驟，不熟悉 SQL 的使用者也難以快速取得需要的資料。本專案著重於三項整合問題：

- **整合分析流程：** 從 MSSQL 取得 OHLCV、移動平均線與 KD 資料，接續完成策略運算、訊號標記、圖表呈現及簡易回測。
- **降低單一指標雜訊：** 綜合 Fibonacci、Granville、KD、突破區間及成交量條件，使用多條件確認並合併短時間內的重複訊號。
- **降低資料查詢門檻：** 將自然語言需求轉換為受限制的結構化查詢計畫，再由程式驗證並產生參數化 SQL，而不是直接執行模型輸出的 SQL 字串。

## 核心功能

1. 依股票代碼與日期範圍查詢歷史行情資料。
2. 計算 Fibonacci 回撤位，呈現可能的支撐與壓力區域。
3. 使用 Granville 法則分析價格與移動平均線的關係。
4. 以 KD 超買、超賣與交叉條件辨識短期動能。
5. 結合近期高低點與成交量判斷突破訊號。
6. 將多策略買賣訊號標記於價格圖表。
7. 以歷史資料進行簡易資金回測，協助比較策略表現。
8. 使用 GPT 產生技術分析摘要，作為研究與判讀輔助。

## 系統流程

```text
MSSQL 股票資料
      ↓
固定條件／自然語言查詢
      ↓
查詢驗證與參數化 SQL
      ↓
技術指標與多策略訊號
      ↓
視覺化、分析摘要與簡易回測
```

## 自然語言查詢的安全設計

系統不直接執行 GPT 產生的 SQL，而是要求模型回傳結構化查詢條件，並在應用程式端完成驗證：

- 僅允許唯讀 `SELECT` 查詢。
- 限制可使用的資料表、欄位、篩選運算子與排序欄位。
- 使用參數化查詢，避免使用者輸入成為 SQL 指令的一部分。
- 限制查詢筆數、篩選數量、排序數量與執行時間。
- 使用獨立的 MSSQL 唯讀帳號，讓資料庫權限成為第二層防護。
- 記錄查詢驗證結果與回傳筆數，不在稽核紀錄保存完整自然語言內容。

## 技術與經驗

- **Python／Tkinter：** 建立分頁式桌面操作介面。
- **MSSQL／pymssql：** 查詢股票歷史資料並管理資料存取。
- **Pandas／NumPy：** 整理時間序列資料及計算分析條件。
- **Matplotlib：** 顯示價格、指標與策略訊號。
- **OpenAI API：** 提供受限制的自然語言查詢規劃與技術分析摘要。
- **策略設計：** 整合 Fibonacci、Granville、KD、突破與成交量條件。
- **安全工程：** 實作 allowlist、參數化查詢、最小權限、查詢上限與稽核紀錄。
